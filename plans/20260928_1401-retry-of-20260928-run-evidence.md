## 3. Root causes and method lessons

- **Browser concurrency is the root cause of the partial sweeps** — logged as backlog `A17`.
  At 3 concurrent browser agents (each told to own one tab) every sweep completed — but not
  cleanly: in round 3 one agent's tab went away when the other agent closed a shared window, and
  it recovered only because it had persisted its accumulator to localStorage. A cap reduces
  contention; it does not remove shared-window teardown.
- **A stalled background tab and a true end of timeline look identical** to `fetch-loop-news`'s
  Pass 2 stop rule. A round-2 agent saw `scrollBy` stall in a background tab; a round-3 agent saw
  X's infinite scroll stop once its tab lost foreground (`document.hidden`) with real wheel events
  too, and un-stalled it by overriding `document.hidden`. One observation each, not a measured
  rate. Day-range searches
  (`from:<h> since:<d> until:<d+1>`) closed every gap they were used on.
- **X posts can be verified without the browser**: `https://api.fxtwitter.com/<h>/status/<id>`
  (and `cdn.syndication.twimg.com/tweet-result?id=<id>&token=a`) return author, `created_at`
  and full text. The retry's refuters used it for every X item that reached the KB, which kept
  verification out of the shared browser.
- **A workflow agent returned a placeholder** (`"item": "test"`, evidence `example.com` /
  `"hello world"`) and the workflow passed it on as a completed check — this repo's defining
  defect, in the tooling. Round 2 added a guard (retry once, then record FAILED), proven after
  the fact against real outputs: it rejects the round-1 stub on content, passes all 9 real
  round-2 outputs, and rejects the stub reshaped into round 2's schema. Limit: a real output
  that legitimately quotes `example.com` would be flagged.
- **A correction can over-correct, and review rounds catch it late.** The first critic found
  `docs/29` asserting that Autopilot is built on OpenClaw on Steinberger's word alone; the fix
  swung to "that link rests on Steinberger". The second critic found the first-party source both
  missed — Microsoft's Autopilot CVP, Omar Shahine: "We are building Autopilot on @openclaw" —
  which the Steinberger post quote-tweets. Check what a cited post *quotes* before calling a
  claim single-sourced.
- **Entering a worktree while workflow agents run breaks their shell.** Agents started in the
  primary checkout had nearly every Bash call refused once the parent entered the worktree, and
  fell back to WebFetch — which this repo forbids for verbatim quotes. The round-2 judge then
  re-verified with `curl`. Separately, the isolation guard refuses git-free loops ("names git in a
  form too complex"); writing the loop to a script and running `bash <file>` works.

## 4. What this evidence could not settle

- **When a repost happened.** X exposes only the original post's time, so swyx's repost of Matt
  Pocock's post is attributed as a repost with no reliable in-window date.
- **The raw steipete scrape is not on disk.** Its 193-ID accumulator was read back from the
  shared Chrome profile's x.com localStorage (`__round3_acc`) by the round-3 judge; clearing site
  data erases it. The count-level result above is what survives.
- **The Tag post's replies are only partly read** — roughly 85 of 199 (as of 2026-09-29). Only
  author-written replies matter; the follow-up is logged in `KB_GAPS.md` (retry-pass entries).
- **Durability of the retry's coverage claims** rests on agent-run browser reads cross-checked by
  a judge's own browser reads, not on an independent tool; the fxtwitter checks cover every item
  that reached the KB, not every tier-0 post that was excluded.
